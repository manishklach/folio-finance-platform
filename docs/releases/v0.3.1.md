# Folio v0.3.1 — Dependency maintenance and production bundle refresh

Folio v0.3.1 is a maintenance release for the controlled integrations and production-operations
platform introduced in v0.3.0. It incorporates all outstanding dependency branches into `main`,
refreshes the checked-in production browser bundle, and confirms the complete application and
deployment pipeline against the updated dependency graph.

## Included updates

- Updated `@sentry/node` from 10.70.0 to 10.71.0.
- Updated `pdfkit` from 0.19.1 to 0.20.1.
- Updated ESLint from 10.9.0 to 10.9.1.
- Regenerated `public/build/folio-app.js` with the merged production dependencies.
- Preserved the Folio v0.3 accounting, integration, security, tenant-isolation, import,
  reconciliation, background-job, and production-operations behavior.
- Merged and closed every outstanding remote dependency branch; `main` is the sole remaining remote
  branch at release preparation time.

## Operational impact

- Sentry receives the upstream 10.71.0 SDK maintenance changes used by Folio's production error and
  tracing integration.
- PDF generation now uses PDFKit 0.20.1 for financial-report document output.
- Development linting uses ESLint 10.9.1 with the existing repository rules unchanged.
- No database migration, accounting-policy change, API contract change, or intentional user-facing
  workflow change is introduced by this release.

## Verification

The merged candidate was validated with the repository's complete release pipeline:

- `npm ci` completed and `npm audit --audit-level=high` reported no blocking vulnerabilities.
- All 143 automated tests passed.
- ESLint and Prettier checks passed.
- The Vite production build passed and generated the refreshed client bundle.
- Platform migration and migration-rehearsal checks passed.
- The documented single-node capacity-envelope check passed.
- Dockerfile validation and the production container build passed.
- The production image vulnerability scan passed.
- Production Compose topology and monitoring configuration validation passed.

## Upgrade notes

1. Create and verify an encrypted backup before changing a live environment.
2. Pin the deployment to the immutable `v0.3.1` tag or its image digest.
3. Use Node.js 22.23.2 and npm 11.6.2, then run `npm ci`.
4. Run `npm run ops:preflight` and `npm run migrate:rehearse` under the intended production
   configuration.
5. Build or pull the immutable application image and perform the controlled restart described in
   `docs/deployment-guide.md`.
6. Verify `/livez`, `/readyz`, monitoring, authentication, tenant isolation, report generation, PDF
   output, provider processing, reconciliation controls, and encrypted backup execution.

Although this release contains no new schema migration, operators should continue to run the migration
and backup gates so the deployed environment and recorded release evidence remain consistent.

## Production boundary

This maintenance release does not change Folio's assurance boundary. Production use with live financial
data still requires organization-specific configuration, credentialed provider certification,
representative migration and restore evidence, security and operational approval, and named
CPA/controller validation of accounting policies and generated statements for the exact deployed
commit and image digest. Folio does not claim GAAP certification, audit certification, or SOC 2
compliance solely by virtue of this release.
