# Folio v0.3.0 — Controlled integrations and production operations

Folio v0.3.0 advances the accounting MVP into a substantially more controlled enterprise finance
platform. This release adds transactional workspaces, durable imports and background processing,
native provider reconciliation paths, hardened tenant and webhook boundaries, production operations,
accounting-validation evidence, and an end-to-end deployment runbook.

## Highlights

- Transaction-oriented React workspaces for day-to-day finance operations, approvals, exception
  handling, integrations, imports, reporting jobs, and accounting review.
- Controlled import pipelines with mapping profiles, duplicate policies, preview and approval gates,
  correction lineage, atomic application, and resolvable exception queues.
- Native Plaid, Stripe, Gusto, and HubSpot synchronization and accounting handoffs.
- Durable, tenant-bound background jobs for provider synchronization, imports, reports, artifacts,
  retries, leases, cancellation, and dead-letter recovery.
- Hardened authentication, authorization, multi-tenancy, OAuth credential storage, webhook processing,
  rate limiting, production startup, monitoring, backups, restore drills, and migration rehearsal.
- Accounting invariant tests and a formal CPA/controller validation evidence gate for release approval.
- Complete production deployment and agent-execution documentation, including rollback and disaster
  recovery procedures.

## Transactional finance experience

- Added finance workspaces that move beyond static module views into guided operational flows.
- Added explicit actions and status handling for imports, reconciliation exceptions, provider records,
  approvals, jobs, and report downloads.
- Added tenant-aware workload admission and bounded rate windows for expensive synchronous routes.
- Added persisted asynchronous report generation and downloadable, tenant-isolated artifacts.

## Imports, mapping, and reconciliation

- Added versioned import templates for journals, bank activity, opening balances, customers, contracts,
  invoices, payments, investments, and fixed assets.
- Added saved mapping profiles, mapping lineage, formula-injection defenses, row validation, paginated
  previews, and exact-file replay protection.
- Added configurable exact and fuzzy duplicate policies with evidence-backed review and override.
- Added staged, approved, atomic application so invalid or partially applied imports cannot silently
  reach the ledger.
- Added correction-source generation, full replacement lineage, auditable exception resolution, and
  retryable failure handling.
- Added bank-statement application and matching to uniquely identified posted cash activity, with
  unmatched and ambiguous items routed to controlled reconciliation queues.

## Provider integrations

### Plaid

- Cursor-based transaction synchronization with pagination restart when the upstream data mutates.
- Native bank-feed versions for additions, modifications, pending items, and removals.
- Bound-account reconciliation to posted cash, with unmatched, ambiguous, or changed transactions
  becoming close-visible exceptions instead of silent journal changes.

### Stripe

- Paginated object synchronization, payout settlement expansion, fees, invoices, payments, refunds,
  disputes, and provider-account binding.
- Raw-body signature verification, replay-window enforcement, secret rotation, connection-scoped
  endpoints, and durable webhook ingestion.
- Atomic, idempotent webhook application with worker crash recovery and no duplicate accounting effect.

### Gusto

- Paginated payroll synchronization and normalized payroll totals.
- Controlled payroll accruals, cash reconciliation, cross-foot validation, posted-change detection, and
  independently approved reversal drafts for removed settled payrolls.
- OAuth token encryption, refresh rotation under lease, and revocation controls.

### HubSpot

- Deal, company, line-item, and product synchronization with preserved associations.
- Approved, idempotent ASC 606 contract handoff.
- Fail-closed handling for ambiguous associations, amounts, or changed source records.

## Security and tenant isolation

- Added a complete, fail-closed authorization manifest for API routes.
- Bound cached ledgers, jobs, artifacts, provider connections, OAuth state, and webhook effects to
  verified tenant paths.
- Added session-bound, one-time OAuth state; encrypted token vault storage; and safe credential
  rotation and revocation.
- Added secure-cookie, HTTPS, origin, bind-address, bootstrap-secret, and secret-mount production
  checks.
- Added immutable posted-journal enforcement at the database layer and continued integrity-hash
  verification.
- Added a repository-grounded threat model and broader negative-path tests for authentication,
  authorization, CSRF, cross-tenant access, webhook replay, and provider-account mismatch.

## Production operations and resilience

- Added a hardened runtime container and production Compose stack with the build toolchain excluded
  from the runtime image.
- Added separate liveness and readiness probes, Prometheus metrics with bounded labels, Sentry support,
  structured request logs, graceful shutdown, and routed-alert preflight checks.
- Added encrypted, authenticated backup and restore with tenant-path rebasing and drill evidence.
- Added forward, rollback, failed-migration, and resume rehearsals from the oldest supported platform
  schema, including durable-job rollback protection.
- Added durable queues with leasing, retry, reclaim, cancellation, dead-letter handling, crash recovery,
  artifact retention, and operator audit history.
- Added an end-to-end deployment guide covering host preparation, secrets, TLS, migration, smoke tests,
  monitoring, backup, restore, upgrade, rollback, and disaster recovery.

## Accounting assurance

- Preserves the v0.2.0 accounting scope: controlled double-entry accounting, ASC 606 and receivables,
  SaaS metrics, EBITDA and EPS, broader GAAP workflows, investments, and fixed assets.
- Added generated invariant tests for balanced journals, exact-cent allocation, ASC 606 consideration
  conservation, tenant binding, idempotency, trial-balance integrity, and hash verification.
- Added a traceable accounting-validation pack covering implemented ASC Topics and reporting outputs.
- Added a release gate requiring named, dated approval from a qualified CPA or controller with linked
  evidence and resolved findings.

## Upgrade notes

1. Create and verify an encrypted pre-release backup, then copy it off-host.
2. Pin the deployment to the immutable `v0.3.0` tag or its commit digest.
3. Install the pinned Node.js and npm versions and run `npm ci`.
4. Review all new required production environment values and secret references.
5. Run `npm run ops:preflight` and `npm run migrate:rehearse`.
6. Stop application and worker processes for the controlled migration window.
7. Run `npm run migrate` once, then start the web, webhook-worker, and background-worker processes.
8. Verify `/livez`, `/readyz`, metrics, authentication, tenant isolation, a provider pull, a report job,
   reconciliation controls, journal integrity, and backup execution.

Follow `docs/deployment-guide.md` for the authoritative deployment, rollback, and recovery procedure.

## Important production boundary

This release is an engineering-complete platform candidate; it is not a claim of GAAP certification,
audit certification, SOC 2 compliance, or suitability for unattended use with live financial data.
Before production approval, the exact release commit and image digest still require organization-specific
configuration, credentialed provider certification, representative migration and restore evidence,
security review, operational ownership, and named CPA/controller validation of accounting policies and
generated statements. See `docs/production-acceptance.md` and `docs/accounting-validation-process.md`.
